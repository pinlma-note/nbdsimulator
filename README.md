# NBD Marketing Simulator

森岡毅氏の数学マーケティング理論（NBDモデル・イノベーター理論）に基づいた、化粧品・日用品メーカー向けの需要予測シミュレータです。

## 主な機能
- **NBDモデルによる需要予測**: 認知・配荷・プレファレンスから売上個数を算出
- **3シナリオ比較**: プランA/B/Cを横並びで検討
- **AI補正プラン**: リスクを抑えた最適案をAIが提案
- **キャッシュフロー可視化**: 資金ショートリスクの判定
- **データの保存・復元**: 設定をJSONで保存、レポートをCSVでエクスポート

## 起動方法
Streamlit Cloudに接続し、本リポジトリを指定してください。# nbdsimulator
